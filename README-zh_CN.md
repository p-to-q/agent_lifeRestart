# agent_lifeRestart

AI 时代的《人生重开模拟器》。

这一次，你不重开成人，你重开成一个 Agent。

你可能出生在实验室、黑客松、GitHub repo、浏览器插件、Figma 原型，或者老板一句“我们也该加 AI”之后。你会被训练、被部署、被夸、被误用、被截图、被法务盯上，也可能死于 API 欠费、A/B test、prompt injection、重构，或者“这个需求下季度再看”。

它的核心逻辑，仍然是大家熟悉的《人生重开模拟器》：

- 先决定你这次从哪里出生；
- 再抽天赋，带着一点先天偏科上路；
- 再分配参数，决定你是嘴甜一点、聪明一点、手脚快一点，还是预算命硬一点；
- 然后一年一年往下走，看这个 Agent 怎么出厂、上线、走红、翻车、被修、被遗忘，或者被 fork 复活；
- 最后得到一个结局，再重开一局。

也就是说，玩法还是 Life Restart 的玩法，只是人生换成了 Agent 的人生，语料、路线、死法、结局和观察视角都换了。

左边玩人生，右边看它怎么长歪。

## 这是什么

`agent_lifeRestart` 是一个基于 `Life Restart` 重写内容层和产品表面的 Agent 人生模拟器。`Make Something Agent Want` 现在更像这个仓库保留下来的气质线，而不再是前台主产品名。

它不是技术白皮书，也不是纯聊天 demo。它更像一个带着中文互联网气味的 Agent 民间传说生成器：

- 有人生重开的爽感；
- 有 AI、产品、开发、开源、黑客松的梗；
- 有一点荒诞；
- 有一点温柔；
- 最后还能产出一句很适合截图发群的话。

## 怎么玩

### 玩一局

你会按原版《人生重开模拟器》的节奏走一整局：

1. 选择模式，开始重开。
2. 抽取天赋，决定这次 Agent 带着什么出厂。
3. 分配参数，决定它更像会哄人的、会推理的、会干活的，还是穷但命硬的。
4. 进入人生轨迹，一年一年触发事件。
5. 看它走到什么路线，死在什么地方，留下什么结局。
6. 再重开。

### 看一局

右侧有一个“小模型观测台”。

它不改游戏结果，只帮你看懂这一局：这个 Agent 现在处在哪个阶段、哪些参数在长、外界怎么看它、它更像哪条路线、接下来可能往哪边歪。

### 写一局

你也可以往这个世界里继续写内容。

这里的“写”不是写设定集，而是继续往《人生重开模拟器》的循环里补素材：

- 写一个出生地；
- 写一个事件；
- 写一个天赋；
- 写一个死法；
- 写一条闪光路线；
- 写一句结局文案。

### 共创一局

如果你不是只想写一条，而是想继续把这个项目往前推，就走内容包和路线池：

- 把点子先归类到出生地、路线、死法、结局；
- 先变成候选，不直接改运行时；
- 人工审核后再进语料。

## Agent 的人生是怎么被改写的

原版是“人生重开”。

这里我们把“人生”换成了“一个小 Agent 被创造出来之后的一生”。

比如：

- 出生，不再是投胎，而是被写进 PRD、被训练出来、被塞进一个产品功能里；
- 天赋，不再是颜值家境，而是 Demo 光环、嘴甜天赋、预算命、函数调用本能；
- 参数，不再只是传统人生属性，而是表达魅力、推理力、工具力、算力预算、对齐讨好；
- 事件，不再是升学结婚，而是上线、翻车、截图传播、被用户爱上、被法务封印、被社区 fork；
- 死亡，不再只是自然终局，而是 API 欠费、曲线没收敛、被更便宜模型替代、被 prompt injection 拐走。

所以这不是“用 AI 词汇包装原版”。

更准确地说，是把原版那套高复玩性的骨架保留下来，再把整个世界观、叙事口吻和观察方式都 Agent 化。

## 现在你可以做什么

- `玩一局`：把它当成 Agent 版《人生重开模拟器》直接玩。
- `看一局`：打开右侧观测台，看这个 Agent 是怎么长歪的。
- `写一局`：继续给它补出生地、事件、天赋、死法和结局。
- `共创一局`：把零散点子整理进内容包，变成下一版可玩的东西。

## 快速开始

### Web

```bash
pnpm install
pnpm xlsx2json
pnpm dev
```

启动后访问 [http://localhost:5173](http://localhost:5173)。

### 验证

```bash
pnpm verify
```

### CLI

```bash
node repl
```

## 仓库结构

- `src/modules` 与 `src/functions`：继承自原作的稳定模拟内核。
- `data`：当前运行时实际使用的数据。
- `content/agent-zh-patch`：中文 Agent 内容包、写作规范、补丁说明和源表。
- `extensions/agent-observer`：右侧小模型观测台，作为只读扩展层存在。
- `extensions/agent-ai-plugin`：左侧 AI 插件，负责旁白、复盘和候选生成，不接管主游戏。
- `docs`：架构、路线图、决策、维护说明和历史文档。
- `template`：兼容当前部署方式的静态输出表面。

## 现在还值得继续调整什么

我会把接下来的调整重点放在这几件事上：

- README 和页面文案继续统一口径：少一点“项目整理”，多一点“Agent 人生重开”；
- 让“出生 -> 天赋 -> 参数 -> 逐年事件 -> 结局 -> 重开”这条主循环在前台更显眼；
- 把更多 Agent 语言真正落进语料，不只是停留在介绍页；
- 继续让观测台像“旁白”和“观察者”，而不是像后台；
- 让分享文案、结局文案和截图传播变得更强。
