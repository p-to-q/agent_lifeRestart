# Credits

`agent_lifeRestart` is an independent p-to-q product fork built from `Life Restart`.

## Current Project

- Product direction, Agent theme, Chinese corpus, observer panel, and co-creation surface: `p-to-q`
- Current repository: <https://github.com/p-to-q/agent_lifeRestart>

## Original Project

The replayable life-simulation core comes from `VickScarlet/lifeRestart`, the original open-source `Life Restart / 人生重开模拟器` project.

- Original repository: <https://github.com/VickScarlet/lifeRestart>
- Original license: MIT

We keep the original license and upstream attribution while evolving the product direction, content pack, and extension architecture independently.

## Frontstage Rule

The product frontstage should present `agent_lifeRestart` first: what this version is, how to play it, how to observe a run, and how to co-create content.

Original author, upstream project, inherited UI/assets, and license attribution should remain visible here, in `NOTICE`, and in project documentation, but should not occupy the main product CTA, banner, GitHub button, or player onboarding copy.
