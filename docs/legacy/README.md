# Legacy Notes

This directory stores context inherited from the original `Life Restart` project shape.

It exists so the repository can present itself as a new product without erasing where the runtime and deploy surface came from.

## Preserved Legacy Areas

- the original gameplay core;
- the current GitHub Pages style deployment surface under `template/`;
- build output compatibility through `template/public`;
- historical assumptions in the original README and localized README.

## Current Principle

Legacy material is reference material, not the default public face of the repository.
