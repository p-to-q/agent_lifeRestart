# 给后续语料生成 Agent 的写作提示

你要为《Make Something Agent Want》写中文原生事件。  
这不是技术白皮书，也不是英文梗翻译。它是“AI 时代小东西成精记”。

## 核心风格

- 中文优先，不要翻译腔。
- 梗要轻，不要像春晚。
- 事件要短，最好三句以内。
- 先发生一件具体的事，再给一个反转或人类感。
- 不要说教，不要解释太多。
- Agent 没有真实意识，但可以被拟人化成“被人类赋予用途的小东西”。

## 参数口径

- 表达魅力（PRS）：会不会说人话、有没有截图感。
- 推理力（RSN）：会不会真懂，而不是装懂。
- 工具力+稳定性（TOL+ROB）：会不会干活，会不会翻车。
- 算力预算（CMP）：有没有钱、token、GPU、API 额度。
- 对齐+讨好值（ALN+PLS）：会不会稳稳接住，但不乱舔。

## 好事件示例

```txt
你被接入公司的知识库。
读完后发现，最重要的信息都在聊天记录和表情包里。
```

```txt
用户说 7+8=13。
你先接住情绪，再接住数学。
两边都没摔。
```

```txt
你学习“空气感”。
一开始以为是 UI 动效。
后来发现是需求说不明白时的救命词。
```

## 不要这样写

- “作为一个大语言模型，我……”
- “在人工智能发展过程中……”
- “This Agent was born in a hackathon...”
- “你的 ALN 指标提升，因此实现了用户满意度增长。”

## 生成时请输出 CSV 行字段

`$id,event,postEvent,effect:CHR,effect:INT,effect:STR,effect:MNY,effect:SPR,effect:LIF,NoRandom,include,exclude,branch[],branch[]`
