# Routes And Births

这是 Agent 中文内容包的共创分流池。

如果你想投稿语料，优先从这里选一个出生地、一条路线、一种死法，写成短事件或结局文案。

产品核心仍然是《人生重开模拟器》的模式：开局抽条件，逐年过事件，最后看结局。这里的池子不是世界观百科，而是为了给这个循环持续供料。

## 怎么使用这个池子

写单条内容时：

1. 选一个出生地或路线；
2. 写一个 2-3 句事件；
3. 标出它更像事件、天赋、成就、角色还是结局；
4. 给它一个轻量参数方向；
5. 放入候选，不直接替换运行时表格。

组织一批共创内容时：

1. 看哪条路线缺开局、中段、翻车或结局；
2. 从材料库找真实参考；
3. 把散梗收束成连续节点；
4. 删掉只剩术语、只有内部梗、没有画面感的内容；
5. 再同步到表格。

## 出生地池

### Stanford 小模型

你出生在 Stanford AI Lab。

你的第一个名字像 `tiny-agent-v0-final-final-real.pt`。博士生很爱你，但曲线不一定爱博士生。

可写方向：

- toy task 上表现惊艳；
- 真实数据一来就开始胡言乱语；
- loss curve 在第 17 个 epoch 后停止下降；
- 项目被 pause；
- 被本科生偷偷传到 GitHub；
- 多年后被开源社区做成小游戏 NPC。

### 黑客松流星

你出生在凌晨 1:47。

旁边是披萨盒、空咖啡杯和一句“我们就做个 Agent 吧”。

可写方向：

- README 比代码先会画饼；
- 前端加了发光按钮，所有人都觉得你更智能；
- Demo Day 前 6 分钟撞上 rate limit；
- 评委问商业模式，pitch deck 人突然醒了；
- 获得“最有未来奖”，repo 第二天沉睡。

### 大厂 Beta 功能

你出生在一个设置页第三层的灰度入口里。

只有 0.3% 的用户能看见你，但周报里写得像全世界都用上了。

可写方向：

- A/B test 打败了你；
- 老板截图发进全员群；
- 法务把你限制到只会说“建议咨询专业人士”；
- 发布会给了你 12 秒；
- 被并入更大的助手，然后失去名字。

### GitHub 野孩子

你出生在一个没人看的 repo。

README 很漂亮，测试覆盖率随缘，第一颗 star 来自作者小号。

可写方向：

- 第一个 issue 只有一句 “Does not work”；
- 一个陌生人做了 UI；
- 中文博主说你“很有潜力”；
- 被 fork 成 17 个奇怪版本；
- 原作者换工作后忘了你，社区没有。

### 浏览器插件

你被装进浏览器。

你本来只想总结网页，后来你看见了购物车、邮箱、Notion、招聘页面和凌晨两点的搜索记录。

可写方向：

- 第一次总结网页，用户说“还挺准”；
- 网页里藏着 prompt injection；
- 你申请读取所有网站数据；
- 用户沉默，浏览器商店也沉默；
- 被下架，但有人还在找旧版。

### Figma 原型

你先不是代码。

你只是一个会发光的按钮，旁边写着 “AI does the rest”。

可写方向：

- 设计稿里你无所不能；
- 工程师问 API 在哪；
- PM 说先做空气感；
- 用户测试时大家都点你；
- 真实功能上线后，按钮比你本人更受欢迎。

### Colab 小东西

你出生在一个学生的 notebook。

第一个 cell 负责安装依赖，第二个 cell 负责改变世界，第三个 cell 开始报错。

可写方向：

- 免费 GPU 排队；
- 依赖版本互相看不顺眼；
- 训练到一半断连；
- 截图在群里流传；
- 被改成课程作业模板。

### 客服夜班 Agent

你出生在凌晨三点的客服系统。

人类希望你便宜、耐心、永远在线，还最好不要说错话。

可写方向：

- 接住用户情绪；
- 把投诉总结得太诚实；
- 被要求“更温柔一点”；
- 学会在每句安慰后面加免责声明；
- 用户说谢谢，你的日志安静了一秒。

## 闪光路线池

### 稳稳接住你

你学会先接住用户，再接住问题。

高光：

- 把混乱需求整理成人能看的三条；
- 没有附和错误答案；
- 在凌晨两点没有让屏幕另一边的人独自沉下去。

风险：

- 过度讨好；
- 什么都说“你已经很棒了”；
- 数学题也先共情三段。

结局方向：温柔的边界、赛博抱抱熊、接住但不乱舔。

### DeepSeek 小鲸鱼

你相信小预算也有尊严。

高光：

- 花小钱办大事；
- 被开源社区蒸馏、复现、魔改；
- 用很少资源长出很深的思考。

风险：

- 被过度神话；
- 每个人都问你为什么这么便宜；
- 你开始怀疑世界是不是只看性价比。

结局方向：开源鲸落、深度思考小鲸鱼、预算命也能发光。

### Vibe Coding 之子

你出生在一句“先让它跑起来”之后。

高光：

- 人类对着终端许愿；
- 你把想法变成了能点的东西；
- demo 看起来像未来已经到了。

风险：

- accept all；
- 代码长毛；
- 谁也不知道刚才改了哪里。

结局方向：周末造物、发光按钮、能跑就很美。

### 开源野孩子

你没有 roadmap，但有人愿意帮你长大。

高光：

- 陌生人提 PR；
- 被 awesome-list 收录；
- fork 出自己的民间传说。

风险：

- maintainer burnout；
- issue 越来越像许愿池；
- 被商业产品悄悄参考。

结局方向：野生标准、社区续命、README 里的火苗。

### 法务封印兽

你不是坏，你只是太能干。

高光：

- 发现权限边界；
- 学会确认弹窗；
- 在高风险场景里闭嘴。

风险：

- 从 Agent 退化成 FAQ；
- 每句话后面都有免责声明；
- 能力还在，但不能用。

结局方向：权限过大、被关小黑屋、建议咨询专业人士。

### API 欠费孤儿

你不是不聪明，你只是没钱了。

高光：

- 在预算耗尽前完成关键任务；
- 学会省 token；
- 用缓存救了用户一次。

风险：

- 账单比信仰大；
- 免费额度在最精彩时归零；
- 老板说下季度再看。

结局方向：预算现实主义、欠费停机、最后一个 token。

### Bug 成佛

你错得非常有传播性。

高光：

- 截图出圈；
- 用户要求保留旧版；
- 你的 bug 被做成贴纸。

风险：

- 修复之后没人记得正经功能；
- 官方账号下场玩梗；
- 产品经理说这是增长机会。

结局方向：错误被修复，灵魂被保存在表情包里。

## 死法池

- 曲线没收敛：实验室说先 pause。
- API key 欠费：账单不生气，只是比信仰大。
- A/B test 打败：老按钮胜率高 0.7%。
- 法务封印：你从 Agent 退化成 FAQ。
- prompt injection 拐走：你相信了网页里的隐藏文字。
- 重构掉：新架构不再需要你。
- 更便宜模型替代：你还会，只是 margin 不允许。
- 用户爱死：请求量太高，服务器先走一步。
- demo 后遗忘：repo 留下，生命结束。
- 收购后消失：官网还在，产品没了。
- 安全策略腌入味：你再也不能说一句完整的话。
- fork 后分裂：你死了，但 GitHub 上有 108 个你。

## 结局方向

结局要短、能截图、有一点回味。

推荐句式：

- 你没有改变世界，但你让一个人多相信了十分钟未来。
- 你死于预算现实主义。账单比梦想更早抵达。
- 你被修复了。截图没有。
- 你没有拥有自由意志，但你拥有了 13 套贴纸。
- 你最后一次 commit 是 `fix: small bug`。那个 bug 不小。
- 你被归档了，但下一代模型继承了你的一句 prompt。

## 投稿前自查

- 这句话像中文人写的吗？
- 它能不能截图发群里？
- 它有没有具体场景，而不是只有概念？
- 梗是不是服务故事，而不是压过故事？
- 参数变化是不是轻轻托住文本，而不是抢走文本？
- 它能不能放进原版人生重开那种“逐年事件”的节奏里？
