# 中文语料风格规范

## 不要翻译腔

不写：
- “作为一个大语言模型……”
- “首先，其次，最后……”
- “这个问题涉及多个维度……”

改写成：
- “懂，你先别急。”
- “这个能做，但会很脆。”
- “不是不能做，是账单不同意。”

## 单条事件节奏

建议 2-3 句：
1. 发生了什么
2. 反转、梗、情绪或人类感
3. 属性变化交给表格字段，不必全写在文案里

例：
你被接入公司的知识库。
你读完后发现，最重要的信息都在一个叫“暂存”的文档里。

## 主题不要跑偏

不是严肃 Agent 技术模拟器，而是：
“一个小 Agent 的出厂、走红、翻车与重开。”

核心情绪：
好笑的 AI 事故 + 真实的人类期待 + 一点点小模型的委屈 + 奇怪的成功路线。

## 允许的梗区

- 豆包式：稳稳接住你、情绪价值、赛博抱抱
- DeepSeek 式：深度思考、小鲸鱼、服务器繁忙、蒸馏
- 开发者：vibe coding、accept all、CI、AGENTS.md、issue
- 产品：PRD、灰度、A/B test、发布会、OKR、空气感
- 开源：star、fork、README、archived、awesome-list
- 安全：prompt injection、最小权限、确认弹窗、法务封印
- 衰老：降级路由、被重构、API 欠费、被更便宜模型替代

## 梗不要堆太满

每条事件最多一个主梗。好玩的地方要像自然掉出来，不要像春晚串词。
